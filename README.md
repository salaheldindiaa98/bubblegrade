# BubbleGrade — GitHub Pages edition

1. Create a public GitHub repository for free GitHub Pages hosting.
2. Upload ALL files from this folder to the repository root. The repository must show index.html beside README.md, rather than inside a second folder.
3. Open Settings → Pages. Select Deploy from a branch, main, /(root), then Save.
4. Open the HTTPS Pages URL shown by GitHub. The app needs no sign-in, API key, database or build command.

Instructor workflow: choose a quiz, set the key, import students, start a session and select a lab / lecture. Confirm the displayed student before each capture. Specific student / rescan replaces a saved score; Anonymous validation saves no grade or photo. Re-export Excel after rescanning.

Share quiz / merge scans lets instructors exchange the same quiz setup and combine result files. Everyone can also create independent quizzes. Data is stored in each browser; live synchronization is not included. Keep quiz setup, answer keys, student rosters, results and backups OUT of the public repository.

Moving from the earlier site: download Back up workspace there, then Restore backup on the new GitHub Pages URL. Existing data does not automatically move between website addresses.

The camera engine has been checked against generated sheets; validate your actual paper layout and phone lighting before official marking.


## v3: full-screen scan update

The camera shows the current student's name, serial and ID plus four numbered corner targets. Position the correct paper and hold steady to accept this student and scan automatically. No confirmation click is required for each camera scan. Remove each paper completely before placing the next. Change student pauses capture while you type a serial or ID. Use Pause to inspect a paper or Group / mode to change your group.

Preview full screen lets you inspect the interface without a camera or printed sheet.

Students now has View lab. Select your lab, tick Absent for the missing students, then use Scan this lab. The quiz title at the top is also a quiz picker on phones.

To update an existing v2 repository, upload and replace the seven files in the Updates Only ZIP in the repository root, commit, and refresh the site. The app retains the same browser storage keys; replacing website code does not erase existing quizzes or grades. The full ZIP is available for a new installation.
